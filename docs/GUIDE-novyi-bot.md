# Новый бот доставки на базе Poytaxt — пошаговый гайд

Как сделать такой же бот (Telegram-бот + мини-апп + админка) для другого кафе: **другое название, логотип, меню и цвета, все функции остаются**.

> Node.js + Express · Prisma + PostgreSQL · React + Vite · Telegram Bot API · Render · Neon · Vercel
>
> **Основа — репозиторий `sariofficial23/poytaxtbot`, ветка `main`.** Бот не пишем заново: копируем готовый и меняем «вывеску».
> Готовые промпты для Claude Code — в файле [`PROMPTS.md`](PROMPTS.md).

**Путь целиком:** копия (Шаг 1) → ребрендинг (Шаг 2) → меню (Шаг 3) → BotFather, Neon, Render, Vercel (Шаги 4–8) → группа курьеров (Шаг 9) → админка и тестовый заказ (Шаг 10) → UptimeRobot (Шаг 11) → чек-лист сдачи.

## 1. Что умеет бот

Один репозиторий, три приложения:

| Папка | Что делает | Где живёт |
|---|---|---|
| `backend` | Telegram-бот (приём заказов, кнопки курьеров) + API + база. Таблицы создаются сами при запуске | Render (бесплатно) |
| `mini-app` | Меню внутри Telegram: главная, меню, карточка блюда, корзина, профиль с заказами | Vercel (бесплатно) |
| `admin-panel` | Панель владельца: заказы, товары, **стоп-лист**, акции, промокоды, курьеры, настройки | Vercel (бесплатно) |

**Путь заказа:** клиент жмёт `/start` → «🍽 Menyuni ochish» → выбирает блюда → оформляет (телефон +998, адрес или локация, промокод) → заказ падает в Telegram-группу курьеров → курьер жмёт «✅ Men olaman», потом «🏁 Yetkazildi» (нажать может только тот, кто взял) → клиенту приходит «Buyurtmangiz yetkazildi» → владелец видит всё в админке.

**Все функции (остаются в каждом новом боте):**

- Меню по категориям с фото, акциями (старая цена) и баннерами
- Корзина, промокоды (% или фикс), бесплатная доставка от порога, апселл Coca-Cola
- Заказ в группу курьеров, кнопки «Men olaman» / «Yetkazildi», уведомление клиенту
- **Стоп-лист:** одной кнопкой скрыть блюдо, которое закончилось
- **Блюда без цены скрыты:** можно залить меню без цен — владелец поставит их сам в админке
- Админка: заказы (просроченные — красный пульс), товары, баннеры, промокоды, отчёт по курьерам, настройки доставки
- Keep-alive: сервер сам себя будит, чтобы не засыпать

## 2. Что взять у клиента

| Что | Подробности |
|---|---|
| **Название** | Как писать в боте, например «Baraka Burger». И username бота (латиницей, заканчивается на `bot`) |
| **Логотип** | Любой формат: PNG, JPG, PDF, **.cdr (CorelDRAW)**, SVG. Claude Code сам переведёт и сделает квадратный логотип, монограмму и иконку |
| **Меню** | PDF макета меню, фото бумажного меню, Excel или текст «Категория — Название — Цена». **Цены можно не давать** — владелец поставит их сам в админке |
| **Фото блюд** | Лучше всего — PDF макета меню: из него фото вырезаются в хорошем качестве. Фото с телефона — только если нет другого |
| **Стиль** | Цвета и настроение («восточный», «молодёжный», «как наше меню»). Claude покажет 3 варианта на выбор |
| **Условия доставки** | Бесплатно от … сум, цена доставки, цена апселла. Можно позже — меняется в админке → Настройки |
| **Почта клиента** | Для аккаунтов Render, Neon, Vercel (см. раздел 3) |

## 3. Аккаунты и сервисы

| Сервис | Зачем | Чей аккаунт | Цена |
|---|---|---|---|
| GitHub | Код, автодеплой | Ваш | Бесплатно |
| Telegram / @BotFather | Бот и токен | Ваш или клиента | Бесплатно |
| Neon (neon.tech) | База PostgreSQL | **Клиента** (его почта) | Бесплатно |
| Render (render.com) | Сервер: бот + API | **Клиента** (его почта) | Бесплатно* |
| Vercel (vercel.com) | Мини-апп и админка | Клиента или ваш | Бесплатно |

> ⚠️ **Главное правило: один бесплатный аккаунт Render = один бот.** Сервер, который не засыпает, тратит ~744 из 750 бесплатных часов в месяц. Два бота на одном аккаунте → в конце месяца сервисы остановятся. Поэтому у каждого кафе свой Render на почту клиента. Создавать много аккаунтов на свои почты нельзя — это нарушает правила Render.

## 4. Шаг 1 — Копия проекта

> **Один раз перед всем:** в репозитории `poytaxtbot` откройте **Settings → General**:
> - **Default branch** = `main` (нажмите ⇄ → `main` → Update);
> - поставьте галочку **Template repository**.

### Вариант А — шаблон GitHub (рекомендую)

1. Откройте `poytaxtbot` → нажмите **Use this template → Create a new repository**.
2. **Include all branches — НЕ отмечайте** (нужна только `main`).
3. Имя, например `barakaburger-bot`, видимость **Private** → **Create repository**.
4. Откройте новый репозиторий в Claude Code (claude.ai/code) и переходите к Шагу 2.

### Вариант Б — через Claude Code

Создайте пустой репозиторий на GitHub, откройте его в Claude Code и дайте **Промпт 1** из `PROMPTS.md`.

## 5. Шаг 2 — Название, логотип, цвета

Положите логотип в чат с Claude Code и дайте **Промпт 2 — Ребрендинг** из `PROMPTS.md`.

Claude Code:
- заменит «Poytaxt» на новое название во всех файлах (список — в разделе 17);
- сделает из логотипа: `logo.jpg` 512×512 (большой логотип), `logo-mark.jpg` (монограмма для маленьких мест — полное название там не читается), `favicon.png`, аватар бота и файлы логотипа в обычных форматах в папке `branding/`;
- покажет **3 варианта дизайна** картинками — вы выбираете букву, только после этого меняется код.

**Где живут цвета** (если захотите поправить сами):

| Файл | Что там |
|---|---|
| `mini-app/src/styles.css` (блок `:root`) | **Все** цвета мини-аппа в одном месте: фон, акцент, текст, карточки, узор. Главные: `--red` (акцент — кнопки и цены), `--bg` (фон), `--card`, `--text`, `--title`, `--on-accent` (текст на кнопках), `--pattern` (узор фона) |
| `mini-app/src/format.js` (`GRADIENTS`) | Цвета баннеров акций |
| `mini-app/index.html`, `mini-app/src/telegram.js` | Цвет шапки Telegram (должен совпадать с `--bg`) |
| `admin-panel/src/styles.css` (`--red`) | Акцентный цвет админки (лучше тёмный — админка светлая) |
| `admin-panel/src/pages/Banners.jsx` (`COLORS`) | Цвета баннеров в админке (должны совпадать с `GRADIENTS`) |

## 6. Шаг 3 — Меню и фото

Меню хранится в `backend/src/models/menu.data.js` и заливается в базу кнопкой **«Обновить меню»** в админке. Фото — в `backend/public/menu/`.

Дайте **Промпт 3 — Меню** из `PROMPTS.md` и приложите меню (PDF, фото, текст).

**Формат позиции** (если правите сами):

```js
const BURGER = 'Burger';
const items = [
  [BURGER, 'Chizburger', 40000],   // [категория, название, цена в сумах]
  [BURGER, 'Big Mac combo', 0],    // 0 = цены пока нет → блюдо скрыто в мини-аппе
];
const PHOTOS = {
  'Chizburger': 'chizburger.jpg',  // файл в backend/public/menu/
};
```

> 💡 **Цены можно оставить пустыми (0).** Все блюда попадут в админку с пометкой «Нет цены — скрыто в мини-аппе». Владелец ставит цену — блюдо появляется у клиентов. Заказать блюдо без цены нельзя.

> ⚠️ **«Обновить меню» нажимается ОДИН раз — при запуске.** Кнопка заменяет все товары на меню из кода: цены, фото и стоп-лист, поставленные в админке, пропадут. После запуска меню меняют только в админке.

Порядок категорий в мини-аппе = порядок их первого появления в `items`.

## 7. Шаг 4 — Бот в BotFather

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя: `Baraka Burger`. Username: `BarakaBurgerBot` (должен заканчиваться на `bot`).
3. BotFather пришлёт токен `123456789:AAH…` — это **BOT_TOKEN**. Никому не пересылайте, не вставляйте в код и в чат с Claude.
4. Аватар: `/mybots` → бот → **Edit Bot → Edit Botpic** → отправьте `branding/bot-avatar.jpg`.

> ⚠️ У каждого кафе — новый бот и новый токен. Если взять токен другого бота, два сервера будут мешать друг другу, и заказы начнут теряться.

## 8. Шаг 5 — База Neon

1. **neon.tech** → регистрация (почта клиента) → **Create project**: имя `barakaburger`, регион **AWS Europe Central (Frankfurt)**.
2. **Connect** → включите **Connection pooling** → скопируйте строку `postgresql://…-pooler…/neondb?sslmode=require` — это **DATABASE_URL**.
3. Экономия бесплатных часов: **Branches → Compute → Edit → max compute 0.25 CU**.

Таблицы создавать не нужно — сервер создаст их сам при первом запуске.

## 9. Шаг 6 — Сервер на Render

1. **render.com** → вход через GitHub (аккаунт Render на почту клиента, GitHub можно подключить ваш).
2. **New → Blueprint** → выберите новый репозиторий и ветку **`main`**. Если репозитория нет в списке — **Configure GitHub** и дайте доступ.
3. Render прочитает `render.yaml` и попросит переменные:

| Переменная | Что вписать |
|---|---|
| `DATABASE_URL` | Строка из Neon (Шаг 5) |
| `BOT_TOKEN` | Токен из BotFather (Шаг 4) |
| `ADMIN_PASSWORD` | Придумайте пароль админки (отдадите клиенту) |
| `MINI_APP_URL` | Пока `0` — заполните в Шаге 8 |
| `COURIER_GROUP_ID` | Пока `0` — заполните в Шаге 9 |
| `NODE_ENV`, `RENDER_EXTERNAL_URL` | Ставятся сами |

4. **Apply / Deploy**, ждите 3–5 минут до статуса **Live**. Скопируйте адрес, например `https://barakaburger-backend.onrender.com`.
5. **Проверка:** откройте `…onrender.com/health` → должно быть `{"status":"ok"}`. Напишите боту `/start` — он ответит приветствием.

## 10. Шаг 7 — Мини-апп и админка на Vercel

Два отдельных проекта Vercel из одного репозитория:

| Проект | Root Directory | Application Preset | Build / Output | Переменная |
|---|---|---|---|---|
| Мини-апп | `mini-app` | **Vite** | `npm run build` / `dist` | `VITE_API_URL` = адрес Render |
| Админка | `admin-panel` | **Vite** | `npm run build` / `dist` | `VITE_API_URL` = адрес Render |

1. **vercel.com → Add New → Project** → импорт репозитория.
2. **Project Name** (например `barakaburger-app`), **Root Directory** — по таблице.
3. **Application Preset = Vite.**

   > ⚠️ Vercel иногда сам ставит **«Services»** и пишет «No detected services» — так проект не соберётся. Выберите **Vite** вручную.
4. **Environment Variables:** `VITE_API_URL` = адрес Render **без «/» в конце** → **Deploy**.
5. Проверьте ветку: в шапке импорта должна быть `main`. Если там другая — после деплоя **Settings → Git → Production Branch = `main`**.
6. Повторите для админки (`barakaburger-admin`, папка `admin-panel`).

> После изменения переменной на Vercel всегда нужен **Redeploy** — иначе мини-апп не увидит новый адрес.

> Бесплатный тариф Vercel (Hobby) по правилам — для некоммерческих проектов. Для бизнеса надёжнее Cloudflare Pages (бесплатно, коммерция разрешена) — Claude Code может перенести за ~10 минут.

## 11. Шаг 8 — Связать бота с мини-аппом

1. **Render** → сервис → **Environment** → `MINI_APP_URL` = адрес мини-аппа (Vercel) → **Save** (сервис перезапустится сам).
2. **@BotFather** → `/mybots` → бот → **Bot Settings → Menu Button → Configure menu button** → адрес мини-аппа, текст кнопки: `Menyu`.
3. **Проверка:** `/start` → появится кнопка «🍽 Menyuni ochish», мини-апп открывается.

## 12. Шаг 9 — Группа курьеров

1. Создайте группу в Telegram, например «Baraka — Kuryerlar», добавьте курьеров.
2. **Добавьте в группу бота** и сразу сделайте его **администратором**.

   > ⚠️ Самая частая ошибка: бота забыли добавить в группу — тогда заказы просто не приходят.
3. Напишите в группе `/id` — бот ответит `Chat ID: -100…`. Если бот не ответил — его нет в группе.
4. **Render → Environment** → `COURIER_GROUP_ID` = это число **вместе с минусом** → **Save**.
5. **Проверка:** админка → **Настройки** → «Проверить группу курьеров». Должно быть «✓ Сообщение отправлено».

> **Ловушка:** когда бота делают админом, Telegram может превратить группу в «супергруппу» с новым ID. Если проверка пишет «ID группы изменился» — впишите новый ID в `COURIER_GROUP_ID`.

## 13. Шаг 10 — Админка, цены, тестовый заказ

1. Откройте адрес админки → войдите паролем `ADMIN_PASSWORD`.
2. **Товары → «Обновить меню»** — загрузится меню из кода. **Нажать один раз.** Пока не нажали — в мини-аппе пусто, видны только категории или ничего.
3. Блюдам с пометкой «Нет цены» поставьте цену: ✏️ → Цена → Сохранить.
4. **Настройки:** порог бесплатной доставки, цена доставки, цена апселла.
5. **Акции:** 1–2 баннера с фото — появятся на главной мини-аппа.
6. **Промокоды** (по желанию): процент или фиксированная сумма.
7. **Стоп-лист:** у каждого блюда кнопка «✓ В наличии» → нажать → «⛔ Стоп-лист» (блюдо скрыто). Фильтр «⛔ Стоп-лист» показывает всё, чего нет.
8. Сделайте **тестовый заказ** из Telegram и проверьте цепочку:

- ☐ Заказ пришёл в группу курьеров с кнопкой «✅ Men olaman»
- ☐ После нажатия кнопка сменилась на «🏁 Yetkazildi», а у другого курьера она не срабатывает
- ☐ После «Yetkazildi» клиенту пришло сообщение о доставке
- ☐ Заказ виден в админке → Заказы, курьер — в отчёте «Курьеры»
- ☐ Промокод применяется, доставка бесплатна от порога, Coca-Cola предлагается только от порога
- ☐ Блюдо в стоп-листе исчезло из мини-аппа и вернулось после снятия

## 14. Шаг 11 — Страховка от «засыпания»

Бесплатный Render засыпает после 15 минут простоя. В коде уже есть keep-alive: сервер каждые 10 минут открывает свой `/health`. В логах Render должна быть строка `⏰ Keep-alive: https://…/health`.

Вторая страховка (бесплатно, 2 минуты): **uptimerobot.com → Add New Monitor → HTTP(s)**, URL `https://…onrender.com/health`, интервал 5 минут, уведомления на почту или в Telegram.

## 15. Частые проблемы

| Что видно | Что сделать |
|---|---|
| Бот не отвечает на `/start` | Проверьте `BOT_TOKEN` на Render → вкладка Logs. Этот токен не должен использоваться другим сервером |
| Мини-апп открывается, **меню пустое** (только категории или ничего) | Админка → Товары → **«Обновить меню»** (один раз). Если не помогло — откройте `…onrender.com/api/products`: если `[]` — меню не залито; если список есть — проверьте `VITE_API_URL` на Vercel → Redeploy |
| Блюдо есть в админке, но нет в мини-аппе | У блюда цена 0 («Нет цены») или оно в стоп-листе |
| Vercel: «No detected services» | Application Preset → **Vite** |
| **Заказы не приходят в группу** | Бот добавлен в группу? Админка → Настройки → «Проверить группу курьеров» покажет точную ошибку. Старый заказ повторно не уйдёт — сделайте новый |
| `chat not found` | Добавьте бота в группу, напишите `/id`, впишите ответ **с минусом** |
| `not enough rights` | Сделайте бота админом группы или разрешите ему писать |
| Первое открытие 20–30 секунд | Сервер просыпался. Проверьте keep-alive в логах и UptimeRobot |
| Новые фото не появились | После изменения меню в коде дождитесь деплоя Render и нажмите «Обновить меню» (это сбросит ручные правки!) |
| Пропали цены / стоп-лист | Кто-то нажал «Обновить меню» — оно перезаписывает всё. Внесите цены снова в админке |
| Render остановил сервис в конце месяца | На одном аккаунте Render два бота. Перенесите второй на аккаунт клиента |

## 16. Бесплатные лимиты и деньги

На бесплатных тарифах один бот спокойно обслуживает обычное кафе: примерно до 1000–2000 постоянных клиентов и 200–300 заказов в день. Лимиты сервисов меняются — перед обещаниями клиенту проверьте их страницы с ценами.

| Когда | Что взять | Примерно |
|---|---|---|
| Больше ~300–500 заказов в день или заказы почти круглосуточно | Render Starter | ~$7/мес |
| База активна больше ~13 часов в сутки | Neon Launch | ~$5–20/мес |
| 10–30 ботов у вас одного | Один VPS (2 CPU, 4 ГБ) на всех | ~$5–10/мес на всех |

**Текст для клиента:** «Бот работает без ежемесячной платы на бесплатных серверах — этого хватает для обычного кафе. Если заказов станет больше ~300–500 в день, сервер нужно будет перевести на платный тариф: примерно $12–30 в месяц. Мы заранее предупредим. На бесплатном сервере первый запрос после долгого простоя может открываться 20–30 секунд.»

| Файл | Зачем трогать |
|---|---|
| `backend/src/models/menu.data.js` | Меню: категории, названия, цены (0 = скрыто), привязка фото |

| `backend/src/config/default.js` | Название бота (`botName`), настройки доставки по умолчанию |
| `backend/src/core/bot.js` | Текст `/start`, сообщения курьерам и клиенту |
| `mini-app/src/screens/Home.jsx` | Шапка главной (название, монограмма) |
| `mini-app/src/components/Onboarding.jsx` | Приветственные экраны при первом входе |
| `mini-app/src/styles.css` (блок `:root`) | Весь дизайн мини-аппа |
| `mini-app/index.html`, `mini-app/src/telegram.js` | Заголовок вкладки, цвет шапки Telegram |
| `mini-app/public/`, `admin-panel/public/` | `logo.jpg`, `logo-mark.jpg`, `favicon.png` |
| `admin-panel/index.html`, `src/pages/Login.jsx`, `src/components/Sidebar.jsx` | Название в админке |
| `package.json` (3 шт.), `render.yaml`, `README.md` | Имена проектов и сервиса на Render |
| `branding/` | Логотип в обычных форматах (SVG, PNG, JPG), аватар бота |

**Переменные окружения:**

| Где | Переменные |
|---|---|
| Render (backend) | `DATABASE_URL`, `BOT_TOKEN`, `ADMIN_PASSWORD`, `MINI_APP_URL`, `COURIER_GROUP_ID`, `NODE_ENV=production` |
| Vercel (оба проекта) | `VITE_API_URL` = адрес Render без «/» в конце |

**Локальный запуск (если нужно):**

```bash
# backend (порт 5000)
cd backend && cp .env.example .env   # заполнить
npm install && npm run dev

# мини-апп (порт 5173) и админка (порт 5174) — в других терминалах
cd mini-app && npm install && npm run dev
cd admin-panel && npm install && npm run dev
```

**Бизнес-правила (по умолчанию, меняются в админке):**

| Правило | Значение |
|---|---|
| Бесплатная доставка | от 100 000 сум |
| Платная доставка | 8 000 сум отдельной позицией «Yetkazib berish» |
| Апселл Coca-Cola | 5 000 сум, только при заказе ≥ порога |
| Телефон | +998 и ровно 9 цифр |
| Блюдо с ценой 0 или в стоп-листе | Скрыто в мини-аппе, заказать нельзя |
| Просроченный заказ | больше 10 минут — красный пульс в админке |
| Курьер | «Yetkazildi» может нажать только тот, кто взял заказ |

## 18. Чек-лист сдачи клиенту

- ☐ Название, логотип, цвета и тексты — нового кафе, **нигде не осталось «Poytaxt»** (Claude Code проверит поиском)
- ☐ Меню сверено с клиентом; список блюд без фото и без цены передан клиенту
- ☐ Бот отвечает на `/start`, кнопка меню открывает мини-апп, аватар стоит
- ☐ Тестовый заказ прошёл всю цепочку (группа → Men olaman → Yetkazildi → клиент)
- ☐ Стоп-лист проверен
- ☐ Клиент знает, что первые заказы в админке — тестовые (удалить их нельзя)
- ☐ Клиенту переданы: адрес админки, пароль, инструкция «как поставить цену / стоп-лист / фото / акцию / промокод»

- ☐ Аккаунты Render, Neon (и Vercel) — на почте клиента, пароли сохранены у вас в менеджере паролей
- ☐ UptimeRobot настроен, уведомления приходят
- ☐ Клиент предупреждён о лимитах бесплатных серверов (текст из раздела 16)
