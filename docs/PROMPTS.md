# Готовые промпты для Claude Code

Копируйте промпт целиком, замените значения в **[квадратных скобках]** и отправьте в Claude Code (claude.ai/code), открыв **новый репозиторий** кафе. Порядок: Промпт 1 (если копируете не шаблоном) → Промпт 2 → Промпт 3 → Промпт 4. Остальные — по ситуации.

Пошаговый гайд — в [`GUIDE-novyi-bot.md`](GUIDE-novyi-bot.md).

---

## Промпт 1 — Копия проекта

*(Только если не использовали кнопку «Use this template» на GitHub.)*

```text
Скопируй весь проект из репозитория sariofficial23/poytaxtbot (ветка main) в этот репозиторий:
папки backend, mini-app, admin-panel, branding, docs, файлы render.yaml, README.md, .gitignore.
Без node_modules и dist. Закоммить и запушь в main.
```

---

## Промпт 2 — Ребрендинг

*(Приложите логотип в любом формате: PNG, JPG, PDF, SVG, .cdr. Если есть PDF меню — приложите тоже: из него берётся стиль.)*

```text
Это копия бота доставки Poytaxt (гайд — docs/GUIDE-novyi-bot.md). Сделай из неё бот для нового кафе:

- Название: [Baraka Burger]. Замени «Poytaxt» везде (список файлов — в разделе 17 гайда):
  backend/src/config/default.js (botName), mini-app/src/screens/Home.jsx,
  mini-app/src/components/Onboarding.jsx, mini-app/index.html, admin-panel/index.html,
  admin-panel/src/pages/Login.jsx, admin-panel/src/components/Sidebar.jsx, README.md.
  Имена в трёх package.json (+ package-lock.json) и render.yaml: [barakaburger]-backend и т.д.
  В конце проверь поиском, что слова «Poytaxt» и «poytaxt» нигде не осталось.
- Тексты приветствия (Onboarding и /start в backend/src/core/bot.js) — под это кафе:
  [бургеры и хот-доги]. Язык текстов — узбекский (латиница), как сейчас.
- Логотип (во вложении): переведи в картинку, если нужно (.cdr тоже). Сделай:
  logo.jpg 512×512 (полный логотип) и logo-mark.jpg 512×512 (монограмма для маленьких мест —
  полное название там не читается) и favicon.png 64×64 в mini-app/public и admin-panel/public.
  В branding/ положи: логотип SVG, PNG без фона, PNG на фоне бренда, квадратный JPG 2048×2048,
  bot-avatar.jpg для BotFather. Старые файлы Poytaxt из branding/ удали.
- Дизайн: все цвета мини-аппа — в одном блоке :root в mini-app/src/styles.css.
  Сначала покажи мне 3 варианта главного экрана и меню картинками (скриншоты мини-аппа
  на тестовых данных) в стиле [описание стиля / «как наше меню»] под цвета логотипа.
  Код меняй только после моего выбора. После выбора поменяй также цвет шапки Telegram
  (mini-app/index.html, mini-app/src/telegram.js), GRADIENTS в mini-app/src/format.js и COLORS
  в admin-panel/src/pages/Banners.jsx, акцент админки --red в admin-panel/src/styles.css.
- Проверь сборку (npm run build в mini-app и admin-panel), сделай скриншоты экранов,
  закоммить и запушь.
```

## Промпт 3 — Меню

*(Приложите PDF макета меню, фото меню или список. Цены можно не давать.)*

```text
Вот новое меню (во вложении: [PDF / фото меню / список]). Замени полностью меню в
backend/src/models/menu.data.js:

- Категории в таком порядке: [Burger, Hot-dog, Lavash, Ichimliklar …]
  (или: в порядке, как в меню).
- Названия — точно как в меню. Покажи, что исправил в написании.
- Цены: [возьми из меню / вот фото ценников / оставь 0 — владелец поставит в админке].
  Позиции с ценой 0 должны остаться в файле (они скрыты в мини-аппе, пока нет цены).
- Удали старые фото Poytaxt из backend/public/menu/.
- Фото: вырежи из PDF меню (pdfimages), привяжи к позициям по названию, обрежь в квадрат
  800×800. [Фото со снимков телефона НЕ используй.] Если фото есть только на снимках — вырежи оттуда.
- Проверь: каждое фото из PHOTOS существует, лишних файлов нет.
- В конце дай список: позиции без фото и позиции без цены.
- Закоммить и запушь.
```

## Промпт 4 — Ветка main и проверка перед деплоем

```text
Проверь проект перед деплоем: npm run build в mini-app и admin-panel, node --check в backend,
npx prisma validate. Убедись, что всё в ветке main и main — ветка по умолчанию.
Если что-то не так — исправь, закоммить и запушь в main.
```

## Промпт 5 — Добавить блюда или категорию позже

```text
Добавь в меню backend/src/models/menu.data.js категорию [Desertlar] с позициями
(во вложении [фото/PDF/список]). Фото вырежи и обрежь 800×800, цены [из меню / 0].
Остальные позиции не трогай. Закоммить и запушь в main.

Напомни мне: после деплоя новые блюда проще добавить вручную в админке (Товары → Добавить),
потому что «Обновить меню» сбросит цены и стоп-лист, выставленные в админке.
```
