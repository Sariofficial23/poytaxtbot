# Poytaxt — Telegram-бот доставки еды

Бот на Python (aiogram 3) с меню, корзиной, оформлением доставки/самовывоза и приёмом заказов в группу персонала. Языки: русский и узбекский.

## Что умеет

**Клиент:**
- выбор языка (RU / UZ);
- меню по категориям: фото, описание, цена, выбор количества;
- корзина: ➖/➕, очистка, сумма;
- оформление: доставка (геолокация или адрес текстом) или самовывоз → телефон (кнопкой или вручную) → комментарий → способ оплаты (наличные / карта) → подтверждение;
- проверка часов работы и минимальной суммы заказа;
- «Мои заказы» и уведомления о смене статуса;
- контакты заведения.

**Персонал / администратор:**
- новый заказ приходит в группу (или админам в личку) со всеми данными, ссылкой на карту и геоточкой;
- кнопки статусов: Принят → Готовится → В пути / Готов к выдаче → Выполнен (или Отменён). Клиент сразу получает уведомление;
- `/stats` — статистика и выручка;
- `/reload` — перечитать `menu.json` без перезапуска бота;
- `/broadcast текст` — рассылка всем пользователям;
- `/id` — показать ID чата (нужно для настройки);
- `/admin` — список команд.

## Структура

```
bot/
  __main__.py      запуск бота
  config.py        настройки из .env
  db.py            база SQLite (пользователи, корзина, заказы)
  menu.py          загрузка menu.json
  texts.py         все тексты RU/UZ — тут можно менять формулировки
  keyboards.py     кнопки
  services.py      тексты корзины и заказов
  handlers/        логика: user (меню, корзина), order (оформление), admin
menu.json          МЕНЮ — редактируется без программирования
.env.example       образец настроек
```

## Пошаговая инструкция — что сделать вам

### Шаг 1. Создайте бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Введите название (например, `Poytaxt Kafe`) и username (должен заканчиваться на `bot`).
3. Скопируйте **токен** — он понадобится в шаге 4. Никому его не показывайте.
4. Там же по желанию: `/setuserpic` (логотип), `/setdescription` (описание), `/setabouttext`.

### Шаг 2. Узнайте свой Telegram ID
Напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш ID (число). Это `ADMIN_IDS`. Если админов несколько — соберите ID всех.

### Шаг 3. Создайте группу для заказов
1. Создайте группу в Telegram (например, «Poytaxt — заказы»), добавьте туда сотрудников и вашего бота.
2. После запуска бота (шаг 5) напишите в группе `/id` — бот ответит ID группы (вида `-100…`). Это `ORDERS_CHAT_ID`.
3. Если группу не делать — заказы будут приходить администраторам в личку (тогда каждый админ должен сначала нажать `/start` у бота).

### Шаг 4. Заполните настройки
Скопируйте `.env.example` в `.env` и заполните:

| Параметр | Что это |
|---|---|
| `BOT_TOKEN` | токен из шага 1 |
| `ADMIN_IDS` | ID админов через запятую |
| `ORDERS_CHAT_ID` | ID группы заказов (можно заполнить после первого запуска) |
| `CAFE_NAME`, `CAFE_PHONE`, `CAFE_ADDRESS` | название, телефон, адрес (адрес показывается при самовывозе) |
| `CURRENCY` | валюта, например `сум` |
| `DELIVERY_FEE` | стоимость доставки (0 — бесплатно) |
| `MIN_ORDER` | минимальная сумма заказа (0 — без ограничения) |
| `WORK_HOURS` | часы работы, например `10:00-23:00` (можно через полночь: `18:00-03:00`) |
| `UTC_OFFSET` | часовой пояс; Ташкент = `5` |

### Шаг 5. Запустите бота

**Вариант А — на своём компьютере (для проверки):**
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```
Бот работает, пока открыто окно терминала.

**Вариант Б — на сервере 24/7 (для работы):** арендуйте недорогой VPS (Ubuntu), установите Docker и выполните:
```bash
git clone https://github.com/sariofficial23/poytaxtbot.git
cd poytaxtbot
cp .env.example .env && nano .env      # заполнить настройки
docker compose up -d --build           # запуск в фоне, автоперезапуск при сбоях
docker compose logs -f                 # посмотреть логи
```
Также подойдут Railway / Render / любой хостинг Python (команда запуска: `python -m bot`).

### Шаг 6. Заполните меню
Откройте `menu.json`. Сейчас там пример — замените его своими блюдами:

```json
{
  "categories": [
    {
      "id": "pizza",
      "name": {"ru": "🍕 Пицца", "uz": "🍕 Pitsa"},
      "items": [
        {
          "id": "pizza_margarita",
          "name": {"ru": "Маргарита", "uz": "Margarita"},
          "description": {"ru": "Томаты, моцарелла, базилик", "uz": "Pomidor, motsarella, rayhon"},
          "price": 65000,
          "photo": "https://ссылка-на-фото.jpg",
          "available": true
        }
      ]
    }
  ]
}
```

Правила:
- `id` — уникальный, **только латиница, цифры, `_` и `-`**, до 30 символов;
- `price` — целое число без пробелов;
- `photo` — прямая ссылка на картинку или `null` (без фото);
- `available: false` — временно скрыть блюдо (стоп-лист);
- названия можно писать одной строкой, если узбекский перевод не нужен: `"name": "Маргарита"`.

После правки отправьте боту `/reload` (от админа) — меню обновится без перезапуска.

> Пришлите мне ваше меню (текст, фото меню, Excel — что угодно), и я сам переведу его в `menu.json`.

### Шаг 7. Проверьте
1. `/start` → выбрать язык → сделать тестовый заказ.
2. Убедиться, что заказ пришёл в группу, нажать статусы — клиенту должны приходить уведомления.
3. `/stats` у админа.

## Частые вопросы

- **Бот не отвечает** — проверьте `BOT_TOKEN` и что бот запущен (`docker compose logs -f`).
- **Заказы не приходят в группу** — бот должен быть участником группы, `ORDERS_CHAT_ID` должен начинаться с `-100`.
- **Бот пишет «Сейчас мы закрыты»** — проверьте `WORK_HOURS` и `UTC_OFFSET`.
- **Ошибка в menu.json** — бот покажет её на `/reload`; чаще всего это лишняя/пропущенная запятая или кавычка.
- **Где данные** — файл `data/bot.db` (SQLite). Делайте его резервную копию.
